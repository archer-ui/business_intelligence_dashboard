# Milestone 5 — Interactive Visual Analytics

## 1. Overview

Milestone 5 converts the analysis completed in Milestones 1–4 into an interactive Business Intelligence dashboard.

The dashboard allows users to filter the dataset, monitor key performance indicators, explore sales and profitability, analyse trends over time, and view decision-support insights.

The application was developed using Python, Pandas, Streamlit and Plotly.

---

## 2. Objectives

The main objectives of Milestone 5 were to:

- Develop an interactive Business Intelligence dashboard.
- Provide filters for exploring different parts of the dataset.
- Display key business performance indicators.
- Visualise sales and profitability.
- Analyse sales trends over time.
- Integrate relevant findings from previous milestones.
- Provide decision-support insights.
- Allow users to inspect filtered records.

## 6. Data Preparation

The dashboard loads the processed dataset from:

```text
Data/sampledata_processed.csv
```

The application validates that important fields are available before continuing.

Required fields include:

- `Sales`
- `Profit`
- `Category`
- `Region`

### Order Date

The `Order Date` field is converted to a datetime value so that it can be used for chronological analysis.

```python
df["Order Date"] = pd.to_datetime(
    df["Order Date"],
    errors="coerce"
)
```

### Profit Margin

Where required, profit margin is calculated as:

```text
Profit Margin = Profit / Sales × 100
```

Invalid or missing values are handled during preparation.

## 8. Key Performance Indicators

The dashboard displays four main KPIs.

### Total Sales

The total sales value for the currently selected data.

### Total Profit

The total profit generated by the currently selected data.

### Total Orders

The number of unique orders where `Order ID` is available.

### Overall Profit Margin

Calculated as:

```text
Overall Profit Margin =
Total Profit / Total Sales × 100
```

This provides an overall measure of profitability for the selected records.

## 10. Time-Series Analysis

The M5 dashboard improves the treatment of dates by aggregating sales by calendar month.

The `Order Date` field is converted into a monthly time index:

```python
trend_df["Month"] = (
    trend_df["Order Date"]
    .dt.to_period("M")
    .dt.to_timestamp()
)
```

Sales are then grouped by month and sorted chronologically.

```text
Order Date
    ↓
Calendar Month
    ↓
Monthly Sales
    ↓
Chronological Trend
```

This ensures that the trend is displayed in the correct chronological order.

The dashboard displays:

- Monthly sales
- First-month sales
- Latest-month sales
- Percentage change across the selected period

The percentage change is calculated as:

```text
Percentage Change =
(Latest Sales - First Sales)
/
First Sales × 100
```

## 17. Limitations

The M5 dashboard has several limitations:

- It uses a processed historical dataset rather than a live database.
- The dashboard focuses primarily on descriptive and diagnostic analysis.
- It does not provide a predictive modelling system.
- Advanced interactive statistical analysis is not included in M5.
- Some features depend on specific columns being present in the processed dataset.

These limitations provide opportunities for further development in Milestone 6.
