# Milestone 5 Report
## Interactive Visual Analytics System

**Project:** Business Intelligence Dashboard  
**Milestone:** 5  
**Status:** Completed  

---

## 1. Introduction

Milestone 5 focuses on developing an interactive Business Intelligence dashboard based on the data preparation, feature engineering, visual analysis and statistical analysis completed in Milestones 1–4.

The objective was to move from static analytical outputs towards an interactive visual analytics system where users can explore the data through filters, key performance indicators and interactive visualisations.

The dashboard was developed using Python, Pandas, Streamlit and Plotly.

---

## 2. Objectives

The main objectives of Milestone 5 were to:

- Develop an interactive Business Intelligence dashboard.
- Provide users with interactive filtering capabilities.
- Display key business performance indicators.
- Visualise sales and profitability.
- Analyse sales performance across categories and regions.
- Analyse sales trends over time.
- Integrate relevant findings from previous milestones.
- Provide decision-support insights.
- Allow users to inspect filtered data.

---

## 3. Relationship to Previous Milestones

Milestone 5 builds directly on the work completed in the previous stages of the project.

| Milestone | Main Contribution |
|---|---|
| M1 | Data exploration and understanding |
| M2 | Data preparation and feature engineering |
| M3 | Visual analysis and visualisation |
| M4 | Statistical analysis and validation |
| M5 | Interactive visual analytics dashboard |

The processed dataset created during the earlier milestones is used as the foundation for the M5 dashboard.

This creates a progression from data exploration and preparation to analysis and finally interactive presentation.
